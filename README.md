# Anup Singh Lodh Portfolio

A modern personal portfolio website for Anup Singh Lodh, a Computer Science undergraduate focused on backend development, browser automation, and full-stack web applications.

The site is built as a React + TypeScript portfolio with animated sections, richer visual transitions, interactive project previews, and a backend-first technical presentation based on the resume content.

## Highlights

- Animated hero section with kinetic name treatment, command-style copy, pointer tilt, and magnetic call-to-action buttons.
- Canvas-based automation/network visual that replaces the earlier static preview block.
- Scroll progress indicator, reveal-on-scroll sections, technology ticker, and animated section transitions.
- Resume-based content for experience, education, projects, certifications, scholarship, leadership, and contact.
- Project cards with interactive mini previews for the e-commerce platform, portfolio website, and scientific calculator.
- Expanded technical stack including React, TypeScript, Node.js, Express, MongoDB, Puppeteer, Docker, GitLab CI, Vite, and Postman.
- Responsive layout with reduced-motion support for accessibility.

## Getting Started

Install dependencies:

```bash
npm install
```

Run the development server:

```bash
npm run dev
```

Open the local site:

```text
http://127.0.0.1:5173/
```

Do not open `index.html` directly with `file://`; this project is a Vite app and should be served through the dev server or a production build.

## Build

Create a production build:

```bash
npm run build
```

Preview the production build locally:

```bash
npm run preview
```
